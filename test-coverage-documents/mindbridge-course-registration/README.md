# Test Coverage Document — MindBridge Course & Tutor Registration

## About

A test coverage document for a fictional edtech application's multi-step
registration feature (browse sessions → add to cart → mock checkout).

This artifact was produced as a graded assignment for the
[Microsoft Junior QA/Software Tester Professional Certificate](https://www.coursera.org/professional-certificates/microsoft-junior-qa-software-tester)
on Coursera.

## What it demonstrates

- **Test type identification** — functional, negative/error-handling,
  regression, usability, and responsive design testing, each scoped to
  what the feature actually needs.
- **Environment strategy** — assigning each test type to DEV, QA, or
  STAGING based on data sensitivity (anonymized vs. realistic PII) and
  environment stability, not habit.
- **Defect documentation** — two known pre-existing defects (an HTTP 500
  triggered by unvalidated special-character input, and a sub-400px
  responsive layout bug), each with reproduction environment and
  reasoning.
- **Pass/Fail criteria** — concrete, observable conditions for each test
  type rather than vague acceptance language.
